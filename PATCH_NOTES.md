# DJMAKER patch 0004 — Light theme contrast

Исправляет низкий контраст текста в светлой теме после compact UI patch.

Изменения:

- глобальная типографика использует `ON_SURFACE` вместо неявного цвета;
- вторичный текст использует `ON_SURFACE_VARIANT`;
- NavigationRail явно использует theme-aware цвета для подписей;
- DataTable получает контрастные стили текста и заголовков;
- добавлены регрессионные тесты против фиксированных WHITE/BLACK цветов.

Патч рассчитан на установленный `DJMAKER_patch_0003_compact_ui.zip`.
