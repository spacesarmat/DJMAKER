# DJMAKER patch 0034 — редактор тегов по двойному клику

## Что изменено

- Двойной клик по строке трека в «Медиатеке» открывает существующий редактор тегов.
- Двойной клик по третьей строке с путём по-прежнему открывает Explorer/Finder с выделением файла.
- Редактор перестроен в компактную двухколоночную форму и редактирует Title, Artist, Album, Album Artist, Genre, Year, Track, Disc, BPM и Key.
- В редакторе показаны технические параметры файла и отдельный результат DSP-анализа BPM/Key/Camelot, чтобы не смешивать рассчитанные значения с файловыми тегами.
- Добавлен просмотр встроенной обложки и staged-замена/удаление перед нажатием «Сохранить».
- Для записи embedded artwork принимаются только JPEG/PNG размером до 32 МБ.
- Запись встроенной обложки поддерживается для MP3/ID3, FLAC и M4A/MP4.
- После сохранения DJMAKER перечитывает файл, пересчитывает SHA-256/mtime, обновляет SQLite и content-addressed кэш обложки без полного пересканирования библиотеки.
- Если запись обложки завершается ошибкой после успешной записи обычных тегов, SQLite всё равно синхронизируется с уже изменённым файлом.
