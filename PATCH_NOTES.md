# DJMAKER — патч 0042: полный анализ BPM-сетки

База: патч `0041a`. Накладывать после 0041a.
Python-зависимости и `pyproject.toml` не изменены. Повторный `pip install` не нужен.

Схема SQLite повышена с версии 6 до 7. Перед первым запуском рекомендуется сделать
резервную копию `library.sqlite3`.

## Что добавлено

- Essentia runtime `r6` возвращает все обнаруженные позиции долей трека;
- сохраняются точный BPM, первая доля, предполагаемая первая сильная доля,
  стабильность темпа и уверенность определения сильной доли;
- по BPM и сильной доле строится постоянная сетка с тактами и музыкальными
  квадратами 4/8/16/32 такта;
- добавлена привязка позиции к ближайшей доле или кратному шагу;
- полный результат хранится в SQLite отдельно от редактируемых файловых тегов;
- старые треки с BPM, но без сетки, автоматически возвращаются в очередь анализа;
- добавлена таблица ручных опорных точек с каскадным удалением. Она подготавливает
  хранение редактируемой/плавающей сетки для следующего этапа;
- экран «Аудио-модули» показывает отдельный прогресс полного анализа сетки;
- старый runtime `r5` не используется для нового анализа и автоматически заменяется
  на `r6` через менеджер аудио-компонентов.

## Ограничения этого этапа

- автоматическая сетка пока постоянная, размер такта — 4/4;
- первая сильная доля определяется эвристикой энергии четырёх фаз;
- визуальный редактор сетки будет отдельным следующим патчем;
- монтажная лента пока не переведена на новую сетку — это следующий этап после
  редактора.

## Важно о runtime

После публикации кода в GitHub нужно один раз запустить
`scripts/trigger_essentia_build.ps1`. Workflow соберёт и опубликует runtime `r6`
для Windows x64, macOS Intel и macOS Apple Silicon. До публикации release новый
полный анализ недоступен, но медиатека и ранее реализованные функции продолжают
работать.
