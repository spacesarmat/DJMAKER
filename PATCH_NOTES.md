# Patch 0027 — Smooth waveform track switching

## Плавное переключение треков

- waveform использует `on_tap`, а не `on_tap_down`, поэтому вложенный GestureDetector больше не запускает playback до разрешения gesture arena строки;
- смена audio source сериализована через `asyncio.Lock`;
- новый source сначала полностью загружается через `on_loaded`, и только потом UI плеера атомарно переключается на новый трек;
- события `duration / position / state` предыдущего source игнорируются во время короткой фазы загрузки;
- старый и новый waveform больше не перерисовываются промежуточными состояниями;
- быстрые повторные клики используют revision-маркер: устаревший запрос не запускает промежуточный трек;
- после готовности source блокировка снимается до `play()`, поэтому события нового трека сразу обновляют UI;
- добавлен timeout загрузки source, чтобы повреждённый/неподдерживаемый файл не мог навсегда заблокировать переключение.

## Совместимость

Схема SQLite, waveform-данные и настройки не меняются. Патч затрагивает только логику preview-player и regression-тесты.
