# DJMAKER — исправление 0041a: видимая монтажная лента

База: патч `0041`. Накладывать после 0041.
Python-зависимости, `pyproject.toml` и схема SQLite не изменены.
Повторный `pip install` не нужен.

## Что исправлено

На Windows экран «Монтаж переходов» открывался, но вместо ленты показывалась
пустая серая область. Причиной был горизонтально прокручиваемый `Row` с
`expand=True` и без фиксированной высоты: desktop-клиент Flet 0.86.5 получал
некорректные ограничения для очень широкого `Stack` временной шкалы.

- прокрутка переведена на горизонтальный `ListView`;
- монтажной области задана фиксированная высота 272 px;
- отключено растягивание ленты на всю оставшуюся высоту окна;
- панель масштаба больше не использует растягивающий spacer внутри `wrap`;
- кнопки уменьшения, увеличения и «Вместить» остаются видимыми;
- нижняя панель выбранного перехода больше не вытесняется за пределы экрана.

Логика Cue, квадратов, перетаскивания, сохранения переходов и FFmpeg-preview
не изменена.

## Проверки

Linux, Python 3.14.7, Flet 0.86.5:

- целевые тесты ленты, переходов, SQLite и UI: 24 теста, OK;
- полный regression: 212 тестов, OK;
- `compileall` и `git diff --check`;
- чистое наложение 0041 → 0041a с повторным regression.

Windows native GUI в этой среде не запускался. После установки проверить через
`flet debug windows .`: лента должна иметь тёмный фон, две дорожки A/B, waveform,
горизонтальную прокрутку, панель масштаба и нижние кнопки переходов.
