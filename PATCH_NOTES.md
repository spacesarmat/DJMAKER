# DJMAKER — патч 0037: сортировка медиатеки

## Изменения

Рядом с поиском добавлены список «Сортировка» и кнопка направления:

- Исполнитель / название — порядок по исполнителю, затем по названию.
- Название — независимо от исполнителя.
- BPM — результат DSP, при отсутствии корректного значения — файловый тег.
- Тональность Camelot — 1A, 1B, 2A, 2B … 12A, 12B.
- Дата добавления в медиатеку — не дата изменения музыкального файла.
- Год выпуска — год из тега, включая даты вида 2024-06-01.
- Длительность.

Стрелка вверх означает возрастание, вниз — убывание. Выбор поля и направления
сохраняется в settings.json и восстанавливается после перезапуска.
Изначальный порядок — исполнитель / название по возрастанию.

Сортировка применяется в SQLite ко всей найденной выборке до LIMIT.
Существующее ограничение отображения в 1000 треков сохранено.
Треки без корректного значения идут в конце в обоих направлениях.
Текст сортируется без учёта регистра, включая кириллицу.
Для Camelot используются результат анализа, затем тональность из тега;
поддерживаются коды Camelot и обычные обозначения (Am, C major, F# minor).
Сортировка тональностей не является подбором гармонически совместимых треков.

Запрос поиска сохраняется при переключении порядка. Сортировка обновляет
только область медиатеки; выделенный трек центрируется, если остаётся в выдаче.
При ошибке сохранения настроек прежний выбор сохраняется и показывается ошибка.

## Установка

База: патч 0036 / main, коммит 3949375. Накладывать поверх 0036.

1. Остановите DJMAKER (Ctrl+C в терминале запуска).
2. Сохраните резервную копию заменяемых файлов или проекта.
3. Распакуйте ZIP в C:\Users\ANDYBUM\PycharmProjects\DJMAKER.V.2
   с заменой файлов и сохранением относительных путей.
4. В терминале PyCharm с активным окружением проекта выполните:

```powershell
python -m compileall -q src tests
python -m unittest discover -s tests -v
```

При успешных проверках запустите:

```powershell
flet debug windows .
```

Зависимости не менялись: повторный pip install не нужен.
Миграция или обнуление БД не нужны. Музыкальные файлы патч не изменяет.
