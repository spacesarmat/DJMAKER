# DJMAKER patch 0028 — track row badges and file reveal

Инкрементальный патч поверх `0027`.

## Изменения

- первая строка трека: `Исполнитель - Название` + компактные теги Key и BPM;
- BPM и Key сначала берутся из DSP-анализа, затем используются файловые теги как fallback;
- вторая строка: длительность + теги года, формата, bitrate, sample rate и каналов + альбом;
- третья строка показывает полный путь как link-like элемент;
- двойной клик по пути открывает расположение файла:
  - Windows: `explorer.exe /select,`;
  - macOS: `open -R`;
  - прочие платформы: родительская папка через `xdg-open`;
- системный файловый менеджер запускается неблокирующим `subprocess.Popen` без shell;
- новые теги используют семантические цвета текущей темы.
