# Patch 0026 — Library search + global theme editor

## Медиатека

- поиск вынесен в отдельный тематический блок `SURFACE_CONTAINER`;
- добавлены иконка поиска, кнопка очистки и счётчик найденных треков;
- живой поиск использует debounce 220 мс, чтобы не перестраивать до 1000 строк на каждый символ;
- SQLite-поиск расширен на `title`, `artist`, `album`, `album_artist`, `genre`, `extension`, source `musical_key`, DSP `analysis_key`, Camelot и путь.

## Глобальный редактор темы

- пользовательские override-цвета сохраняются отдельно для Light и Dark;
- поддерживаются 14 ключевых ролей Material ColorScheme;
- формат ввода — `#RRGGBB`, некорректные значения не применяются;
- валидный цвет сразу показывается во всём интерфейсе;
- пустое поле наследует значение выбранной базовой темы;
- доступны действия «Сохранить», «Вернуть сохранённое» и «Сбросить текущую схему»;
- несохранённый preview автоматически откатывается при уходе с экрана настроек;
- редактор работает как с seed-палитрами, так и с полностью заданными схемами «Чистый графен»/«Строгий».

## Совместимость

Схема SQLite не меняется. Старые `settings.json` продолжают загружаться: новые словари override-цветов по умолчанию пустые.
