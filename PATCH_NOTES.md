# DJMAKER patch 0030 — Write analyzed BPM/Key to file tags

- Результаты BPM/Key анализа теперь записываются обратно в аудиофайл.
- Запись точечная: остальные теги и неизвестные пользовательские поля не переписываются.
- Key сохраняется как обычная тональность со строем, например `A minor`; Camelot остаётся отдельным рассчитанным значением DJMAKER.
- Поддержаны существующие write-back контейнеры DJMAKER: ID3/MP3, FLAC/Ogg, MP4/M4A, ASF/WMA и APE-style tags.
- Если анализ не определил BPM или Key, существующее значение соответствующего тега не удаляется.
- После изменения файла DJMAKER перечитывает метаданные, пересчитывает SHA-256/mtime/size и синхронизирует SQLite до сохранения результата анализа.
- Для EasyMP4 зарегистрирован `INITIALKEY`, чтобы записанный Key читался обратно обычным `inspect()`.
