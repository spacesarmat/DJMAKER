# Patch 0022 — wider Waveform and UI responsiveness

- Waveform в строке медиатеки растянут примерно вдвое: ширина полосы увеличена с `2 px` до `5 px` при прежних 60 пиках и небольшом промежутке `1 px`.
- Отрисовка waveform переведена с 60 отдельных `ft.Container` на два SVG-слоя (`base + progress`). Это резко уменьшает количество Flet-контролов в большой медиатеке.
- Прогресс активного waveform обновляется только при переходе на следующую из 60 полос, а не на каждом событии позиции плеера.
- События позиции/длительности/состояния плеера используют частичные `page.update(*controls)` вместо полной перерисовки страницы.
- При переключении уже созданного Audio source обновляется сам Audio service и компактный набор player controls, без полной перерисовки медиатеки.
- Автоматический Waveform-анализ ограничен одним worker-процессом одновременно; FFmpeg запускается с `-threads 1`, чтобы фоновый анализ меньше конкурировал с UI за CPU.
- Схлопывание PCM в 60 пиков теперь выполняется за один проход без промежуточного Python-списка всех сэмплов.
