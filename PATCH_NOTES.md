# DJMAKER patch 0036 — компактное поле поиска

## Что изменено

- У `TextField` поиска в Медиатеке убрана внутренняя рамка.
- Внешний тематический контейнер поискового блока сохранён.
- Кнопка очистки перенесена внутрь поля поиска в правую часть через `suffix`.
- Крестик показывается только при непустом запросе.
- По клику поле очищается, поиск сбрасывается сразу и список обновляется без debounce-задержки.
- Отложенный запрос после очистки не применяется; повторный ввод запускает новый поиск.
- Поиск обновляет только область медиатеки, а изменение видимости крестика — только кнопку.
- Крестик доступен и для строки из пробелов, чтобы её тоже можно было очистить.

## Установка

1. Закройте DJMAKER и сохраните резервную копию заменяемых файлов.
2. Распакуйте ZIP в `C:\Users\ANDYBUM\PycharmProjects\DJMAKER.V.2`
   с заменой файлов и сохранением относительных путей.
3. Из корня проекта выполните `python -m unittest discover -s tests -v`.
4. Запустите `flet debug windows .`.

Зависимости не менялись, повторный `pip install` не нужен.
Архив предназначен для проекта с установленным патчем 0035 либо текущего main.
Не накладывайте его на 0034 или более раннюю версию.
